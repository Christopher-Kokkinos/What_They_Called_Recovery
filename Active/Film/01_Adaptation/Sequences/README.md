# Sequence Outline

This directory holds the major sequence-level outline for the screen adaptation.

Each sequence should state its dramatic objective, source coverage, major events/reveals, character movement, ending turn and rough screen-time range when known.

Sequence planning occurs before detailed screenplay scene conversion so the whole film remains visible.
