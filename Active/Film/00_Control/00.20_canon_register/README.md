# Film canon register

`canon_register.csv` is a source-indexed ledger for story facts that affect film continuity. It is not a replacement for the novel or the source decomposition. Add only bounded claims with a chapter/source-unit citation; distinguish a source event from character testimony, a character inference and a film invention. Use `unresolved` until evidence resolves a conflict. Do not mark an inference as verified because it appears in a dossier.

Suggested IDs: `CAN-0001` onward. `authority` is `novel`, `film_decision` or `unresolved`; `evidence_kind` states how the claim is known. A film decision also needs its decision-log ID. Never store protected source prose here when a citation suffices.
