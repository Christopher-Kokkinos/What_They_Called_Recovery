# Adaptation

This directory converts the canonical novel into a controlled screen-adaptation source layer before Blender production.

## Authority
The novel/publication master remains canonical source material. Film adaptation material is derivative and belongs only here.

## Required order
1. Decompose source chapters into meaningful beats/scene candidates.
2. Register adaptation decisions in `../00_Control/adaptation_register.csv`.
3. Preserve or deliberately transfer each unit's narrative function.
4. Draft approved material into the Fountain screenplay.
5. Create production scene packets.
6. Only then create shot specifications for Blender.

## Structure
- `SCREENPLAY_FORMAT.md` — screenplay-source conventions.
- `Screenplay/` — canonical film screenplay source.
- `Scene_Packets/` — production-ready scene specifications.

Use `workflows/film-adaptation-preparation.md`.

Film adaptation is allowed to compress, merge, omit, relocate, visualise or otherwise transform source material only when the decision is explicit and traceable. It does not change canonical manuscript prose or publication authority.
