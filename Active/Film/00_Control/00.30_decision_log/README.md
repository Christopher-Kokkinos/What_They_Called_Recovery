# Film decision log

Create one dated `DEC-####_short-title.md` per material production or adaptation decision. Use `_TEMPLATE.md`; link source-unit/scene/asset IDs, alternatives, approval, validation and superseding decision. The existing `adaptation_register.csv` still records each source-unit disposition. A discussion or draft is not an approval.

Do not rewrite old decisions when direction changes. Add a superseding entry and update affected registers and project state.
