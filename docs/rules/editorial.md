# Editorial rules

- British English is the default narrative/editorial standard for the UK setting.
- Preserve character-specific lexical differences where intentional (for example Zoe's American usage).
- Do not alter voice, pacing, imagery, dialogue content, plot, chronology, knowledge state or reveal order unless explicitly authorised.
- Copy-edit changes are limited to clear grammar, punctuation, spelling, consistency and approved terminology corrections.
- No open-ended polishing.
- Substantive prose changes require proposal + explicit approval before implementation.
- Maintain the locked style sheet under `Active/Editorial/`.
- Every editorial intervention must be traceable in a report or diff.
